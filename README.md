# LEGO-J: n Approach to Overcome the Challenges to Modularise Large, Legacy Java Applications

Welcome to the official repository for **LEGO-J**. This repository contains the replication package and source code for our proposed map-based approach designed to effectively modularize legacy Java projects.

## 📌 About The Project
LEGO-J introduces a novel mapping approach to analyze, restructure, and transition traditional Java applications into a modular architecture (e.g., Java Platform Module System - JPMS). 

To demonstrate the effectiveness of our approach, this repository includes the application of LEGO-J on two well-known open-source case studies: **Ptidej** and **JHotDraw**.

## 🌿 Branch Structure
To keep the codebase clean and make the "before and after" comparison straightforward, the project is divided into specific branches. Please switch to the respective branch to view the source code for each state of the case studies:

| Branch Name | Case Study Status | Description |
| :--- | :--- | :--- |
| `1-mini-Ptidej-No-JPMS` | **Ptidej (Unmodularized)** | The original, unmodularized source code of the Ptidej project. |
| `2-mini-Ptidej-JPMS` | **Ptidej (Modularized)** | The Ptidej project successfully modularized using the LEGO-J approach. |
| `3-wumpz-jhotdraw-original` | **JHotDraw (Unmodularized)**| The original, unmodularized source code of the JHotDraw project. |
| `4-wumpz-jhotdraw-modularised`| **JHotDraw (Modularized)** | The JHotDraw project successfully modularized using the LEGO-J approach. |
